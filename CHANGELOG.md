# Changelog

## 0.2.0 — First public release

- Rust/ratatui fullscreen terminal candy gallery with 23 curated entries.
- Search, categories, descriptions, favorites, recent history, and themes.
- Pacman, yay, and paru installation with native confirmation and AUR review.
- Single-program, category, and all-catalog installs with a dry-run option.
- Animation sequences, Matrix cycling, screensaver mode, and Space collection.
- Hyprland/Kitty workspace presets with menu and CLI access.
- Idempotent placement and delayed effect startup after terminal positioning.
- Arch package recipe, desktop launcher, manual page, and contribution guide.
